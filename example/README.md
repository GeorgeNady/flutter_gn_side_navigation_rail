# flutter_gn_side_navigation_rail Example

A demonstration application showcasing the v2.0 features of `flutter_gn_side_navigation_rail`.

## Features Demonstrated

- **External State Control**: Programmatic navigation and collapse/expand using `SideBarController`.
- **Native Typography**: Seamless inheritance of the app's `ThemeData` font family without hardcoded font constraints.
- **Custom Header Widget**: Custom branding row combining an image logo and text header.
- **Disabled Item State**: Navigation item with `isDisabled: true` showing disabled styling and custom tooltip.
- **Custom Toggle Icons**: Customizing the collapse/expand toggle icons with `expandedToggleIcon` (`Icons.menu_open`) and `collapsedToggleIcon` (`Icons.menu`).
- **Responsive Layout**: Adapting smoothly to screen resize and narrow display widths.

## Running the Example

```bash
flutter pub get
flutter run
```
